# Рабочий контент по зонам

*Обновлено 2026-09-03.* Заполняется замером с сервера, а не со слов: строка появляется, когда
конкретный класс конкретной расы **сдал** квест. Ничего не выводится по догадке.

**Правило.** Зона считается полностью рабочей в части квестов, когда **все классы выполнили все её

**Как читать.** «Сдано» — квесты, закрытые хоть кем-то; это доказывает, что цепочка проходима, и
только. **«Закрыли все побывавшие»** — сколько квестов зоны закрыл *каждый* из побывавших там
классов, и через дробь — сколько этих классов было. Именно это число обязано дорасти до «квестов
в зоне». Число без знаменателя лживо: зона, пройденная одним классом от начала до конца, показала
бы «18 / 1 кл.» — а правило запрещает объявлять её рабочей по одному классу. Пока классов в
знаменателе меньше, чем зона должна принять, полной она не считается ни при каком числе.

Прочерк вместо имени — зона ещё не названа; имена берутся у самого сервера.

<summary><strong>English</strong></summary>

<br>

*Updated 2026-09-03.* Filled from server measurements, never from opinion: a row appears when a
specific class of a specific race has actually **turned in** a quest.

**The rule.** A zone counts as fully working, in quest terms, when **all classes have completed all
of its quests** — for a race's own starting zone only that race's classes, for every later zone
absolutely all of them.

**How to read it.** *Сдано* counts quests closed by anybody, which proves the chain is passable and
nothing more. *Закрыли все побывавшие* is how many of the zone's quests were closed by *every*
class that has been there, over the number of such classes. That number must reach the zone's
quest count. A bare number would lie: a zone walked end to end by a single class would read
"18 / 1 кл.", exactly the claim the rule forbids. While the denominator is smaller than what the
zone owes, no number makes it complete.

A dash instead of a name means the zone is not yet named; names come from the server itself.
